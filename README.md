# Music Garden

A calm music app for a 4-year-old learning piano: her class book on a real
staff, **Learn** (the app waits for each note), **Play!** with the beat
(Great / Good / Early / Late / Missed per note, timing chart, replay of what
she played), and a note-reading quiz. Plays from on-screen keys, a MIDI
keyboard (Chrome) or the microphone listening to any piano.

Static files only — open `index.html` from any web server.

Staging: https://xxc2xx.github.io/music-garden/staging/
